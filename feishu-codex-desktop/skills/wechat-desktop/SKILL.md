---
name: wechat-desktop
description: 连接、启动、断开或诊断微信 ClawBot 对本机 Codex 桌面会话的控制。通过扫码授权，无需飞书凭据或安装 OpenClaw；支持与飞书并行运行。
---

用户明确要求连接微信时，使用本插件的 `wechat_login`。这是微信 ClawBot 的扫码连接，使用腾讯公开 iLink 协议。
调用需要真实 Codex 桌面上下文。缺少绑定时，先在当前桌面会话终端执行插件的 `src/bind-desktop.mjs`，不得猜测管道或伪造其他会话。
返回 `qrPath` 后，用绝对路径图片展示二维码，提示用户用手机微信扫一扫并在手机确认。二维码由服务端登录内容本地编码，不用图片生成模型，也不要把二维码或授权凭据发布到外部服务。
登录后台最多等待五分钟，微信服务可能更早让二维码过期，以 `wechat_login_status` 状态为准；避免频繁轮询。
`need_verifycode` 时仅在用户提供手机显示的配对验证码后调用 `wechat_verify_code`；不要猜测验证码。
过期或用户要求刷新、换绑时调用 `wechat_login(refresh=true)`。已有正常连接时不重复扫码。
登录确认后，`bridge_status` 的微信通道为 `connected` 才说明消息轮询已经连接。桥接运行时会自动载入新凭据。
如果桥接没有运行，使用 `start_bridge` 启动，再检查状态。仅配置微信即可启动，不要求飞书 App ID / Secret。

引导用户直接用自然语言让助手查找、选择和转交任务；也可 `/help` 或 `/projects` 后回复项目和会话编号。选中后仍是助手，只有 /resume 明确进入会话直聊。
支持“下一页”“上一页”、`/page 2`、`选择 12` 和 `/use 12`。回复必须给出当前页数、全局编号和具体的下一步示例。
已有会话保持原模型、项目和上下文；微信、飞书分别保存选中的会话，桌面切换窗口不改变通道的发送目标。
扫码用户身份来自微信登录结果。只允许该账号的私聊控制，不自动授权陌生人、群消息或任何账号发出的 `/pair`。
机器人回声、引用内容和附件不作为新任务。第一版仅支持文字，附件需提示改发文字。
发送或创建结果未知时不要自动重试；先检查真实桌面会话是否已收到消息。

只在用户要求退出或断开微信时使用 `disconnect_wechat`；飞书通道保持运行。
`stop_bridge` 会停止所有通道的桥接，Codex 会话本身继续运行。
凭据和回复上下文存于用户目录 `.codex-feishu-desktop` 的受限本机文件，不打印 token、不放入插件包、不提交 Git。
模型管理使用 `/models`、`/model 模型ID`、`/effort high`；`/model default` 恢复沿用桌面会话模型和强度。
设置按微信账号、通道、主机和会话保存，作为后续任务发送参数，不启动任务，也不保证改变桌面永久配置。
普通对话默认进入操作助手，无需 /assistant 前缀；选择、新建或复制会话后仍是助手。只有明确 /resume、进入直聊或进入会话聊天才转为直聊。助手可用 send_task 转交用户本次明确要求的原文任务给所选 Codex 会话。
`/assistant` 或“操作助手”“返回助手”“切换会话”返回默认助手模式；无需给普通消息添加前缀。`/resume` 进入已有会话的直聊。
操作助手可使用用户指定的 OpenAI 兼容 Chat Completions 接口。用 `assistant_status` 检查，只有用户要求时用 `configure_assistant` 配置，省略 apiKey 保留已有凭据。
助手 API Key 只存于本机 assistant.json，不回显、不发布；固定命令不调用助手模型，助手自然对话会使用接口用量。
继续已有会话通过当前运行桌面 App 的协调 IPC 提交普通用户文字，继承目标会话的供应商、模型和权限。已加载的目标在后台接收消息；未加载时，桥接自动调用桌面导航打开目标，等待其真实会话连接就绪后再发送。这会切换本机当前桌面页面，无需用户手动点击；/open 仍可主动打开所选会话。加载超时或打开失败时明确提示消息未发送。自动打开前和发送前均检查微信账号授权，结果未知不重试，也不回退到跨会话工具结果。此入口不提供执行审批或停止任务，不启动另一个 app-server。
创建、修改和回复读取仍通过真实桌面 app-tools 管道；完整本机列表可只读查询桌面元数据，禁止修改数据库。
当前不能代点执行审批或停止桌面任务。不要用 shell、桌面代码修改或独立 CLI 会话绕过这些限制，也不要声称已经实现 QQ、企业微信或所有桌面功能。
