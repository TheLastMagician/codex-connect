# 更新记录

## 0.3.2

- 删除把用户措辞当作权限的关键词检查，修复“进去会话”等自然请求被误报未授权。
- 操作助手开放插件已支持的全部管理命令，包括通知、复制、归档列表、分页、项目详情和模式切换。
- 支持在一次请求内查找、选择再进入会话；管理操作缓存按目标会话和页面区分。
- 保留配对身份、真实目标、参数和任务原文校验，以及未知执行结果不重试。

## 0.3.1

- 普通消息默认交给操作助手，无需 `/assistant` 前缀；选择、新建、复制会话后仍保留助手模式。
- 新增助手转交任务能力；任务内容直接摘自本次用户消息，交由所选 Codex 会话执行，沿用桌面模型或手机侧覆盖。
- 只有 `/resume`、明确的“进入会话聊天”或「进入直聊」按钮进入直聊；`/assistant` 或“返回助手”退出直聊。
- 旧会话选择状态自动迁移到助手默认模式，保留目标、模型设置及助手历史；之后明确选择的直聊模式可在重启后保留。

## 0.3.0

- 新增 `/models`、`/model`、`/effort`；按通道、账号、主机和会话保存模型与推理强度覆盖，默认沿用桌面会话设置。
- 新增飞书模型卡片按钮；微信和飞书帮助、状态与选择确认显示模型管理和助手入口。
- 新增可配置的操作助手，支持 OpenAI 兼容 Chat Completions 工具调用接口；支持项目/会话查找、选择、模型管理及现有管理操作。
- 未选会话时直接对话使用助手；选中后任务直接发送到 Codex；`/assistant` 和 `/resume` 切换模式。
- 新增本机 `configure_assistant`、`assistant_status` 工具及隐藏 Key 输入配置程序。凭据不包含在仓库或安装包中。
- 校验助手工具参数和真实目标；撤销授权后不执行延迟返回的操作；未知修改结果不重试；重复事件不会再次执行任务。

## 0.2.3

- 插件显示名改为「Codex 连接」，使用生成的新图标。
- 发布完整源码、构建产物、GitHub 仓库插件目录和安装说明。
